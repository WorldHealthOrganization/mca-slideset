# Files for WHO MCA slideset etc

## (for history before initial commit please see <https://github.com/kpeven/MCAslideset>)

| **File**                        | **Usage**                                                               |
|---------------------------------|---------------------------------------------------------------------------------|
| `mca-slideset.Rproj`            | Rproj file for slideset                                                         |
| `Slideset.Rmd`                  | Markdown file with all code for slideset                                        |

# Folders

| **Folder**                      | **Usage**                                                                       |
|---------------------------------|---------------------------------------------------------------------------------|
| `code`                          | All .R code files used in the project                                           |
| `data`                          | Most data files for slideset, some are in WHO/data if multiple use cases        |
| `documentation`                 | Files which document, explain or manage the project                             |
| `figures`                       | All slideset/global strategy figures save to this folder, then copy to ppt/docs |
| `global_strategy_visual_annex`  | The files and code for Global Strategy Visual Annex                             |
| `maps`                          | All organised data for maps and map files                                       |
| `MaternalMort_2000-17`          | R project to generate Maternal mortality files - old                            |
| `MaternalMort_2000-23`          | R project to generate Maternal mortality files - current                        |
| `renv`                          | renv files for slideset proj                                                    |
| `tutorials`                     | How to use R files for Theresa                                                  |
